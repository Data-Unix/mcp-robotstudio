Atencion: ha indicado un host distinto de loopback (127.0.0.1 / localhost). RWS 1.0 en IRC5/RobotWare 6 usa HTTP sin TLS en puerto 80; los datos consultados circulan por su red local. Chrome pedira permiso explicito solo para ese origen.
Para controlador virtual local use 127.0.0.1 o localhost.
En RobotStudio Virtual Controller suele ser 80 u otro puerto asignado a RobVC.
Nunca se guarda en disco ni en chrome.storage.local: se guarda unicamente en chrome.storage.session (acceso restringido a contextos confiables de la extension) y se descarta al cerrar el navegador. Esta extension rechaza autenticacion HTTP Basic.

Como averiguar el puerto en Windows (PowerShell)

$ids = (Get-Process RobVC).Id
Get-NetTCPConnection -State Listen | Where-Object { $ids -contains $_.OwningProcess }
